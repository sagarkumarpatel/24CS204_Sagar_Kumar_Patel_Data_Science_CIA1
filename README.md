Smartphone Battery Consumption Analysis

This project analyzes smartphone battery consumption based on screen-on time, application category, network type, and battery temperature.

Objectives
Clean and preprocess the smartphone battery dataset.
Compare battery consumption across applications and networks.
Calculate battery drain per hour.
Analyze usage intensity.
Visualize battery consumption using Scatter Plot and Box Plot.
Tools Used
Python
Pandas
Matplotlib
Seaborn
Google Colab
Key Findings
Gaming consumes the most battery.
5G shows higher battery consumption than 4G.
Higher screen-on time leads to faster battery drain.
